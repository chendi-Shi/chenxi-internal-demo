# 魔搭 Docker 创空间部署

本部署包将 Dashboard、Retrieval Hub HTTP API 和 `/mcp` 放在一个 Docker 服务内，监听 `0.0.0.0:7860`。创空间使用隔离的临时目录并自动载入两份清楚标明为虚构的样例；它不会连接本机目录、OneDrive、真实 PDF 或现有 Hub 数据库。

云端演示允许匿名查询虚构资料，也允许访客修改演示库的检索策略，以便验证 Dashboard 的自定义和服务端排序。来源管理、导入和删除接口仍需管理 Token，因此匿名访问无法调用。策略仅保存在容器临时目录，服务重启后可能还原。不要把内部数据放入此公开演示服务，也不要把它连接到内部 ChatGPT 工作区。

## 创建创空间

1. 在魔搭创建 **Docker 类型**的创空间，保持私有可见性并选择免费硬件。
2. 绑定阿里云账号并完成平台要求的实名认证。
3. 将本仓库部署包推送到该创空间的 Git 地址；新创空间默认使用 `master` 分支，不要强制推送。本仓库根目录的 `Dockerfile` 会构建前端并启动整合服务。
4. 等待构建完成后打开创空间。Dashboard 首页自动连接同源 HTTP API；MCP Streamable HTTP 地址为创空间根地址加 `/mcp`。

Docker 服务必须监听 `0.0.0.0:7860`。不要在部署环境配置任何本机目录挂载或内部资料凭据。部署后设置 `HUB_PUBLIC_URL` 为创空间完整 HTTPS 地址（例如 `https://modelscope.cn/studios/<owner>/<name>`），让 MCP 返回的文档链接能被外部客户端访问。若创空间通过自定义域名提供服务，同时将该域名加入 `HUB_MCP_ALLOWED_HOSTS`；默认值涵盖魔搭国内和国际站的域名。

## 部署前置条件

命令行推送需要在本机配置 `MODELSCOPE_API_KEY`，其值从魔搭个人访问令牌页面取得；不要把令牌发到聊天、写入仓库或放入 Dashboard。首次创建与后续 Git 推送必须使用该魔搭账号有权限的创空间。若账号未完成阿里云绑定或实名认证，应先在魔搭网页完成这些账户步骤。

若工作区还没有魔搭令牌或目标创空间身份，部署包仍可本机 Docker 构建验收；取得令牌并确认创空间 owner/name 后，才能进行账号侧的创建和推送。
