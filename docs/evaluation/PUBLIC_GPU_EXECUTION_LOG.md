## 状态读取规则

原生崩溃可能使 worker 的最后一次 `run_state.status` 停留在 `running`。导出器因此同时保存 worker 状态、监督器阶段和退出码；监督器明确失败时，有效运行状态为 `failed`，即使已有部分完整质量结果，也不会标记整个矩阵完成。
